# 教室用タイマー

授業や試験で使う、全画面表示・音通知付きのブラウザタイマーです。アカウント登録やデータベースは不要です。

このリポジトリは、Privateで管理する正本から生成する独立ソース配布版です。公式サイトの配信元ではありません。公開確認の記録は`release-readiness.json`、脆弱性の非公開報告手順は[SECURITY.md](SECURITY.md)を参照してください。

公式サイトには共通ヘッダー・関連ツールなど独自の外枠があります。この配布版のZIPはこの独立版自身の対応ソースであり、公式サイトの対応ソースを示すものではありません。公式版は公式画面のソース案内で確認します。

## 利用方法

### すぐ使う

[公式サイトで教室用タイマーを使う](https://nobatasu.com/app/tools/timer/)

公式サイトはブラウザだけで利用できます。通常利用ではDockerのインストールは不要です。

### 自分のPCで動かす・改良する

以下のローカル起動手順を使います。Dockerは任意で、Dockerなしでも起動できます。HTMLファイルを直接開く代わりに、`localhost`のHTTPサーバー経由で開いてください。

## ローカルで起動する

### Dockerを使う

Docker Composeが使える環境で、このディレクトリから実行します。

```sh
docker compose up
```

[http://127.0.0.1:8091/](http://127.0.0.1:8091/) を開きます。初回はイメージ取得とビルドが必要です。秘密ファイルや事前のnpm実行は不要です。ソースを編集した後は `docker compose up --build` で作り直します。停止は `docker compose down` です。

### Dockerを使わない

Python 3で確認する場合は、配布物を作ってからそのディレクトリだけを配信します。

```sh
python3 scripts/build.py
python3 -m http.server 8091 --bind 127.0.0.1 --directory build/site
```

## 使い方

1. 30秒〜20分のボタン、または分・秒の入力で時間を設定します。
2. スタートで開始し、一時停止・再開・リセットで操作します。
3. 全画面表示で投影用の表示に切り替えます。Escで戻ります。
4. 授業モードで説明や補助表示を隠せます。

Spaceでも開始・一時停止できます。音の再生にはブラウザでの操作が必要です。端末の消音設定も確認してください。

残り時間は端末の時刻から計算し、タブに戻ったときにも更新します。計測中に端末の時計を手動変更すると、その変更が残り時間に影響します。終了ベルのリセット時は、鳴り始めた音が最大約0.4秒残る場合があります。

## データと通信

- 設定した分・秒はlocalStorageへ保存します。ブラウザデータを削除すると消えます。
- 授業モードはsessionStorageへ保存します。通常はタブを閉じると消えます。
- 保存を拒否する環境でも、ページ内でタイマーを操作できます。
- 名前・名簿・写真の入力、利用履歴の収集、広告・解析処理はありません。
- CSSとアイコンフォントは同梱しています。既定設定では画面の初期表示に第三者CDNを使いません。
- 使い方・画像・プライバシーURLを追加すれば、その設定先へのアクセスが発生し得ます。公開運営者は実際の通信と表示を確認してください。
- サーバー側のアクセスログは、利用するホスティングの設定によります。

## 改変と自己ホスト

`config.js`で表示名・運営者・案内URL・対応ソースURL・版を設定できます。対応ソースURLが空または無効な場合、ソースリンクは非表示になります。ネットワーク公開する改変版では、実際に取得できる対応ソースURLを必ず設定します。外部のロゴ画像は同梱していません。改変版では運営者と名称を適切に変更してください。

既定の「ソースコード」は `./source/timer-source.zip` を指します。ビルド時に、そのビルドに使ったコード、依存素材、文書、テスト、ビルド手順を同梱するため、公開GitHubのURLがなくても配信版自身のソースを取得できます。独自repoへリンクする場合は、配信に対応する版を取得できるURLを設定します。

**ファイルを直接サーバーで編集した場合も、再ビルドしてソースZIPと配布内容を揃えてください。** UIの改変時にソース導線を消さず、授業モードや全画面からも到達できることを確認します。

配信対象は `build/site/` の内容です。repo全体を公開ディレクトリへコピーしません。rootの `/` と任意のサブパスで配信できる相対参照を使用しています。

## 開発とテスト

実行にNode.jsは不要です。ブラウザテストだけで使います。

```sh
npm ci --ignore-scripts
npx playwright install chromium
python3 scripts/build.py
```

別ターミナルで上記HTTPサーバーを起動し、`BASE_URL=http://127.0.0.1:8091/ npm test` を実行します。詳細は [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。

Chrome/Chromiumで主要操作・保存拒否・音声APIの再開・全画面などを自動検証しています。Safari実機と実際のスピーカーからの音は未確認です。授業で使う前に、使用する端末で終了音と全画面表示を確認してください。
